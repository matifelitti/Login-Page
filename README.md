
# 🔐 Responsive Login Page  

A **modern and responsive** login page built using **HTML, CSS, and JavaScript**. This project features a clean UI with a gradient background, an image section, and a functional login form.  

## 📌 Features  

- **🌟 Stylish UI** – A modern login design with a split layout (image + form).  
- **📱 Responsive Design** – Adapts to different screen sizes.  
- **🔒 Remember Me Option** – Checkbox to keep users signed in.  
- **🔗 Forgot Password Link** – Provides an option for password recovery.  
- **🎨 Smooth Hover Effects** – Buttons and links have subtle transitions for better UX.  

## 🛠️ Technologies Used  

- **HTML5** – Page structure.  
- **CSS3** – Styling, layout, and responsiveness.  
- **JavaScript (optional)** – Can be added for form validation.
